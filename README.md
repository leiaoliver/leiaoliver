Full Stack Developer with nearly 5 years of experience building web and mobile products with **React, Next.js, React Native, Node.js and TypeScript**.

I've worked in very different contexts: banking (Banking as a Service), fintech (a white-label financial platform) and, today, projects for international clients, where I also apply AI to report analysis and process automation.

I enjoy working across the stack, from well-structured, responsive interfaces to APIs and data, and seeing what I build make a real difference for the people who use it.
